# Projector Match: downloads

Camera-based white and black matching for projectors, LED walls and flat panels.

## Download the latest version

| Computer | Download |
| --- | --- |
| **Windows 10 / 11** | [ProjectorMatch-Setup.exe](https://github.com/awilusz/projector-match-releases/releases/latest/download/ProjectorMatch-Setup.exe) — installer, no admin rights needed |
| Windows, no install | [ProjectorMatch-Windows-portable.zip](https://github.com/awilusz/projector-match-releases/releases/latest/download/ProjectorMatch-Windows-portable.zip) — runs from any folder or USB stick |
| **Mac** (Apple Silicon or Intel, macOS 11+) | [ProjectorMatch.dmg](https://github.com/awilusz/projector-match-releases/releases/latest/download/ProjectorMatch.dmg) — open it and drag Projector Match to Applications |
| Mac, zip instead | [ProjectorMatch-Mac-app.zip](https://github.com/awilusz/projector-match-releases/releases/latest/download/ProjectorMatch-Mac-app.zip) |

All versions and their changes: [Releases](https://github.com/awilusz/projector-match-releases/releases).

## First launch on a new computer

The app isn't code-signed yet, so each computer asks once:

- **Windows:** at "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** open Projector Match and click **Done** at the warning. Then open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**.

## Using it

Open Projector Match. Chrome (or Edge) opens the app. Nothing else needs installing, and it works with no internet connection at the venue.

- **Windows:** a small window shows the bridge log. Close it to stop.
- **Mac:** it runs in the background. Use **Quit bridge** in the app to stop.

## Updates

When a new version is published here, the app shows **Update available** in its header. Click it, download, and install over the old version. Your show config is kept.

See the *Projector Match Field Guide* from your engineer for how to use the app on a job.
